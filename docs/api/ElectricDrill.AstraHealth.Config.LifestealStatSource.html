Namespace

Selects which entity's stats feed the lifesteal rate lookup when the entity dealing damage resolves to a different entity than the one credited for it (see LifestealAttribution).

public enum LifestealStatSource

Fields

Beneficiary = 1

Use the lifesteal rate stat from the resolved beneficiary only (the entity attribution resolves to, e.g. the ship owning the weapon).

Performer = 0

Use the lifesteal rate stat from the damage performer only (the direct dealer, e.g. a weapon entity). Preserves the pre-ownership behavior.

PerformerThenBeneficiary = 2

Use the performer's lifesteal rate stat if present, otherwise fall back to the beneficiary's.

Sum = 3

Add the performer's and the beneficiary's lifesteal rate stats together.
